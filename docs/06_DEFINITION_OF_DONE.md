# Definition of Done

A task is done only when:
- code is placed in the correct module,
- code compiles under C++20,
- project warnings are reviewed,
- relevant native tests pass through CTest,
- coordinate/unit assumptions are documented,
- no forbidden coupling was introduced,
- the app still runs where relevant,
- the change is small enough to review.

Baseline is done only when the nominal closed-loop scenario demonstrates measurable centering improvement and acceptance metrics are exported.
